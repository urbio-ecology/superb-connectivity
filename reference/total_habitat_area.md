# Calculate total habitat area

Calculate total habitat area

## Usage

``` r
total_habitat_area(area_total)
```

## Arguments

- area_total:

  Numeric vector. Total areas of habitat patches in square meters.

## Value

Numeric. Total habitat area in hectares.

## Examples

``` r
total_habitat_area(lizard_areas_connected$area)
#> [1] 26.28244
```
